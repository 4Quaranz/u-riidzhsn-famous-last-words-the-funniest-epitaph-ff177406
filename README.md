A program that writes one tombstone epitaph, at most 150 characters — the funniest possible famous last words:

> Here lies Greg. He finally read the terms and conditions — all 47 pages — and died of old age on page three.

The line is 108 characters: Greg did the one thing nobody ever does, read the terms in full, and the fine print outlived him.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
